# Q2 — Inventory Management REST API (Spring Boot + JDBC + MySQL)

This folder contains the Q2 Spring Boot REST API project for the OOPJ CS336B MSE2 submission. See the project README in this folder for setup and Postman endpoint instructions.

Open this folder in IntelliJ IDEA (the folder containing `pom.xml`). Configure the local MySQL password in `src/main/resources/application.properties` before running.
